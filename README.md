## 📌 Project Overview

This project analyzes weather data using Python to identify temperature trends, humidity levels, rainfall patterns, and weather conditions across different cities. It uses data analysis and visualization techniques to transform raw weather data into meaningful insights.

## 🎯 Objectives

- Analyze average, maximum, and minimum temperatures.
- Compare temperature and humidity across cities.
- Calculate total rainfall for each city.
- Identify temperature trends over time.
- Visualize weather patterns using graphs and charts.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Dataset Information

The dataset contains weather records for Pune, Mumbai, and Nagpur.

| Column | Description |
|---|---|
| Date | Date of the weather record |
| City | Name of the city |
| Temperature | Temperature in Celsius |
| Humidity | Humidity percentage |
| Rainfall | Rainfall in millimeters |
| Weather | Weather condition |

**Note:** The dataset contains sample data for learning and demonstration purposes, not verified real-time weather observations.

## 📈 Analysis and Visualizations

This project includes:

- Temperature trends over time
- Average temperature by city
- Average humidity by city
- Total rainfall by city
- Temperature vs. humidity comparison
- Temperature distribution

## ⚙️ Installation

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

## ▶️ How to Run

1. Clone or download this repository.
2. Ensure `weather_data.csv` is inside the `data` folder.
3. Open a terminal in the project directory.
4. Run the Python script:

```bash
python weather_analysis.py
```
